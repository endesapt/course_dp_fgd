# Кэш результатов авторов FGD

`analysis_allo_discrete.csv` взят без изменений из репозитория авторов FGD
(Weng et al., USENIX ATC'23, симулятор `kubernetes-scheduler-simulator`),
лицензия Apache-2.0. Используется в `scripts/compare_reference.py` для
сверки нашей реализации FGD (приложение B курсовой).
