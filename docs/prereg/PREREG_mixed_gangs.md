# Mixed PAI blocks: whole + fractional gangs (pre-registration, 2026-11-18)

**Вопрос.** Меняются ли выводы курсовой и статьи, если вернуть дробные
задачи: дробные ганги (52% GPU-спроса гангов PAI) и дробные одиночные?
Конкретно:
1. Разрыв DP-FGD с atomic BestFit и с seq-FGD (P1).
2. Цена ошибки M: prev и uniform против stream (P2–P3, flat-M).
3. Порядок baseline из статьи CAFGD (BestFit, DotProd, Packing, FirstFit,
   Random) в постановке с гангами.

Зафиксировано **до** запуска. Код: дробный DP, seq-FGD и ёмкость
(`Course/src/fgdg2`, 2026-11-18, не закоммичено), тесты `tests/test_gang_frac.py`
и полный набор проходят локально и на сервере.

## Данные

- `make_pai_blocks.py --mixed --load 1.2`, домены MISC / V100 / V100M32
  (локально: 502 / 154 / 122 блока). Целые и дробные задачи, ганги и одиночные.
  Тип GPU — жёсткий домен, как в основной постановке.
- Доля дробных гангов в GPU-спросе блоков: MISC 49.5%, V100 13.8%, V100M32 5.1%.
- **Все** элементы ставит тестируемая политика (`--background gang`): никакого

## Политики и армы

| Арм | Политика | M |
|---|---|---|
| dp_stream / seq_stream / abf_stream | dp, seq_fgd, atomic_bestfit | stream |
| aff / abfgpu / adot / apack / arand | atomic_firstfit, atomic_bestfit_gpu, atomic_dotprod, atomic_packing, atomic_random | stream (не используется) |
| dp_prev / seq_prev | dp, seq_fgd | `stale:` pods предыдущего блока |
| dp_uniform / seq_uniform | dp, seq_fgd | uniform по классам домена (вкл. дробные) |

Для дробных воркеров DP точен по распределению между узлами при
внутриузловом жадном FGD-правиле; seq-FGD — глобальный argmin по
(узел, карта) на каждого воркера. Воркеры одного ганга могут делить карту.
GpuClustering не включён: раннеру блоков не хватает хука observe_placement.

## Метрики

Primary — unalloc@100 (доля нераспределённых GPU-долей при спросе = 100%
ёмкости). Secondary — unalloc@end, доля размещённых гангов. Совпадающие
блоки, bootstrap по кластерам из 10 соседних блоков, Holm по семейству
сравнений внутри вопроса.

## Что считаем изменением выводов

- P1: разрыв DP − aBF меняется более чем на ±0.5 п.п. относительно whole-only
  (−1.98 п.п.) или меняет знак разрыв DP − seq.
- P2/P3: меняется знак `DP − seq` по потере при prev или uniform.
- Отчёт по доменам обязателен (MISC — основная доля дробных гангов).

## Отступление от плана, принятое до полного прогона

- Спецификация `stream` для смешанных блоков **не работает**: она собирает M из
  синтетических «форм гангов» в заголовке и отвергает дробные ганги. Поэтому
  «оракульный» M в смешанной постановке = `stale:<pods этого же блока>`
  (гистограмма воркеров блока, та же конструкция, что у prev и uniform). Армы
  `*_stream` в именах папок означают именно это.
