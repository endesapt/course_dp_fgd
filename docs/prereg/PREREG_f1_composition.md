# F1: факторный состав нагрузки на смешанных блоках (pre-registration, 2026-11-19)

**Вопрос.** На смешанных блоках (778, `2026-11-18_mixed_gangs`) DP − seq-FGD =
−1.32 п.п., а на целых GPU (другие границы блоков) −0.21. Откуда рост? В
смешанных блоках одновременно (a) появились дробные ганги, (b) появились дробные
одиночные, (c) пропал FGD-фон (все элементы ставит тестируемая политика). F1
разделяет вклады **на тех же границах блоков и при том же спросе**.

Зафиксировано **до** любых прогонов F1. Код симулятора не меняется: сервер
`~/fgdg2-run/src` = ветка `fractional-gangs` (`39fc8bd`) по md5.

## Почему не удаление (отступление от HANDOFF §3, решено с автором до запуска)

В исходном плане варианты строились удалением элементов. Проверка спроса на
778 блоках (доля ёмкости, среднее; блоков, где спрос ≥ 100%):

| Домен | full | без дробных гангов | без дробных одиночных | только целые |
|---|---|---|---|---|
| MISC (502) | 1.204 (501) | 0.608 (5) | 1.134 (483) | 0.538 (1) |
| V100 (154) | 1.212 (154) | 1.044 (117) | 1.211 (154) | 1.043 (116) |
| V100M32 (122) | 1.210 (121) | 1.148 (117) | 1.208 (121) | 1.147 (117) |

В MISC (основной домен эффекта) после удаления метрика unalloc@100 не
определена почти ни в одном блоке. Поэтому варианты **сохраняют весь спрос**, а
меняют только то, *как* элементы сгруппированы и кто их ставит.

## Варианты потока (границы блока, элементы, порядок и pods — те же)

| Вариант | Преобразование | `--background` | Что выключает |
|---|---|---|---|
| `full` | нет (результаты `results/pai_mixed/{dp,seq,abf}_stream`, не перезапускаются) | gang | — эталон |
| `splitfracgang` | каждый дробный ганг k×d (k>1, d<1) → k дробных одиночных по d подряд | gang | совместность дробных гангов |
| `splitwholegang` | каждый целый ганг k×d (k>1, d≥1) → k целых одиночных по d подряд | gang | совместность целых гангов |
| `splitall` | все ганги → одиночные | gang | всю совместность (санити: DP ≡ seq) |
| `splitfracgang_fgdbg` | как `splitfracgang` | fgd_q | + дробные одиночные ставит FGD-фон (как в whole-only постановке) |

Расщеплённые воркеры получают `gang_id = <job:task>:<i>`, `gang_size = 1`,
`is_gang = false` и идут подряд на месте ганга; `arrival_index` переписывается
с 0. Pods (гистограмма по воркерам) не меняются, поэтому M и его отпечатки
(`m_whole_sha256`, `m_fractional_sha256`) совпадают с исходными — это проверяется
в `derive_variants.py`. Заголовок (`realized`, `gang_shapes`) пересчитывается
`stream_header`. `full_fgdbg` на исходных потоках невозможен: `MixedPolicy`
с FGD-фоном отвергает дробные ганги по построению.

**Оговорка.** Расщепление снимает не только совместность, но и «всё или ничего»
для этих задач (у всех политик одинаково). Поэтому вклад читается как «вклад
ганг-структуры», а не чистой совместности DP.

## Политики, M, метрики

- Политики: `dp`, `seq_fgd`, `atomic_bestfit`. M = `stale:<pods блока>` (оракул
  по воркерам, как армы `*_stream` в mixed).
- Primary: unalloc@100. Secondary: unalloc@end, доля размещённого спроса.
- Совпадающие блоки; cluster bootstrap по 10 соседним блокам (`cluster_ci` из
  `2026-11-17_flat_m/analyze_flat_m.py`); по доменам и ALL. Holm по семейству
  H1–H3 внутри каждого скоупа.

## Оценки и критерии (записаны заранее)

Обозначим G(v) = DP − seq в варианте v, A(v) = DP − aBF, S(v) = seq − aBF,
парно по блоку.

- **H1 (дробные ганги).** Δfg = G(full) − G(splitfracgang). «Рост из-за
  совместности дробных гангов», если CI(Δfg) < 0 в ALL и в MISC и
  Δfg/G(full) ≥ 0.5 в MISC. Если CI(Δfg) содержит 0, то рост не из-за них.
- **H2 (целые ганги).** Δwg = G(full) − G(splitwholegang); то же правило.
  Ожидание [H]: |Δwg| ≈ 0.2 (по whole-only результатам).
- **H3 (FGD-фон).** Δbg = G(splitfracgang_fgdbg) − G(splitfracgang): меняется ли
  выигрыш DP, когда дробные одиночные ставит FGD. Сообщаем CI, без порога.
- **Санити (обязательна до интерпретации).** |G(splitall)| < 0.05 п.п. в каждом
  домене (на одиночных DP и seq-FGD должны совпасть). Если нарушено, сначала
  разбираемся с кодом, H1–H3 не интерпретируем.
- Те же разложения для A(v) и S(v) показываем описательно, чтобы увидеть, какая
  часть выигрыша FGD-скора над BestFit привязана к гангам.
